### ETAPA 6 - FUNÇÕES

No primeiro código, `dobro(21)` mostra 42 e a média das notas mostra 6.875.
Se testar `dobro(5)`, dá 10. Se testar `media([10, 6])`, dá 8.

1. O código mostra undefined porque a função soma faz a conta, mas não devolve ela. Precisa colocar `return`.

   ```javascript
   function soma(a, b) {
       return a + b;

   ```
   Agora vai mostrar 5.

2. Minha função ficou assim:
   ```javascript
   function ehPar(n) {
       return n % 2 === 0;
   ```

3. `console.log` mostra o valor no console. O `return` devolve o valor da função para poder usar depois.

### ETAPA 8 - CALCULADORA DE MÉDIA

* **8.1.** Fiz uma página com dois campos de nota, um botão para calcular e um lugar para mostrar o resultado.
* **8.2.** Peguei os valores dos campos usando `.value`. Eles chegam como texto, então transformei em número com `Number()`.
* **8.3.** A conta da média ficou assim:
  ```javascript
  function calcularMedia(n1, n2) {
      return (n1 + n2) / 2;
  }
  ```
  Testes:
  * (8 + 7) / 2 = 7.5
  * (10 + 5) / 2 = 7.5
  * (6 + 6) / 2 = 6

  Não posso fazer `n1 + n2 / 2` sem parênteses porque aí a divisão vem primeiro. Com 8 e 6 daria 8 + 3 = 11, mas a média certa é 7.

* **8.4.** Para conferir se a nota é válida, usei:
  ```javascript
  function notaValida(n) {
      return !Number.isNaN(n) && n >= 0 && n <= 10;
  }
  ```
  Testes:
  * notaValida(5) = true
  * notaValida(10) = true
  * notaValida(11) = false
  * notaValida(-1) = false
  * notaValida(NaN) = false

  Ela só aceita números de 0 até 10.

* **8.5.** Primeiro confiro se algum campo está vazio ou se a nota é inválida. Se tiver problema, aparece *Informe duas notas entre 0 e 10.* Se estiver tudo certo, faço a média. Quando ela é 6 ou mais, mostra *Aprovado*. Se for menor que 6, mostra *Abaixo da média*.
